# Warehouse Shop

Simple staff shop: products with up to 5 photos, price and retail link. Staff browse the catalog; there is no online ordering.

- `index.html` – shop page
- `admin.html` – owner page to add/edit products and take or upload photos (login required)
- `config.js` – shop name, currency, Supabase URL + anon key
- `setup.sql` – run once in Supabase SQL Editor

Hosting: any static host (Netlify, GitHub Pages). Data and photos: Supabase free plan.
