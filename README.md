# Warehouse Shop

Simple staff shop: products with photo, price and retail link. Staff pick items and the order is sent to the owner on WhatsApp/SMS.

- `index.html` – shop page
- `admin.html` – owner page to add/edit products and upload photos (login required)
- `config.js` – shop name, phone number, Supabase URL + anon key
- `setup.sql` – run once in Supabase SQL Editor

Hosting: any static host (Netlify, GitHub Pages). Data and photos: Supabase free plan.
